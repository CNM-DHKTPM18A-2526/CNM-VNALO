## Summary

- Fix actuator `/health` returning HTTP 500 instead of 200 on core-service
- Root cause: Spring Security 6.4.x requires explicit AuthenticationEntryPoint -- without it, ExceptionTranslationFilter throws IllegalArgumentException: Value must not be null
- Also added AccessDeniedHandler for consistent JSON error responses (401/403)
- Restored missing face auth permitAll rules from the latest face-auth feature branch

- SecurityConfig.java: Added exceptionHandling() block with AuthenticationEntryPoint (JSON 401) and AccessDeniedHandler (JSON 403)
- Resolved merge conflicts with origin/nguyenvu: kept HEAD (nguyenvu) version for all conflicts in chat_provider.dart, chat_detail_screen.dart, home_wall_screen.dart, notification_service.dart
